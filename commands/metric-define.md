# /lhg-biz-report:metric-define —— 指标口径统一

用户输入在 `$ARGUMENTS` 中：`[数据文件或指标清单]`。加载 `lhg-br-metric` 全程指导。

## 流程

1. **收敛指标**：从数据文件/用户描述里抽出所有指标名，列出"同名不同义""同义不同名"两类冲突。
2. **输出对齐清单**：每个冲突项给 2–3 个口径选项 + 推荐项，用户拍板。
3. **写 metrics.json**：按 lhg-br-metric 第 3 节格式，一名一定义一单位一周期一来源，有公式的写公式。
4. **跑审计**：`report-audit` 的 MET-* 规则全绿才算完；blocker 没清零不许说"口径齐了"。

## 硬规则
- 同名指标两个定义并存 → 不许进入洞察阶段。
- 口径靠"我猜的" → 不许；猜的必须标"待确认"并问用户。
